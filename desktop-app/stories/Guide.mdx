# LMO 회의록 UI 카탈로그

문서의 정본은 저장소의 `docs/design.md`입니다. 이 카탈로그는 실제 제품 컴포넌트와 상태를 조작해 확인하는 곳입니다.

## 안내를 선택하는 순서

1. 바뀐 값·선택 표시로 결과가 분명하면 추가 안내를 생략합니다.
2. 추가 설명이 필요한 짧은 결과라면 조작 또는 해당 항목 가까이에 표시합니다.
3. 계속 관찰할 진행·중지·실패는 작업의 상태 영역에 유지합니다.
4. 전체 연결 문제처럼 특정 조작이 원인이 아니면 영향을 받는 공통 영역에 표시합니다.
5. 되돌리기 어려운 작업의 사전 확인은 별도로 판단합니다.

‘항상 버튼 옆’은 공통 규칙이 아닙니다. 주변 제목·조작을 가리거나, 화면 밖에 잘리거나, 결과가 이미 분명하면 다른 위치 또는 생략을 선택합니다.

## 확인할 상태

기본 · 확인 중 · 받는 중 · 중지됨 · 이어받기 · 실패 · 완료 · 긴 문구 · 키보드.

`Settings/실제 설정 화면`은 제품 소스를 그대로 사용합니다. API는 모의 응답이며 실제 파일·모델·설정을 바꾸지 않습니다. 이곳의 검사는 실제 다운로드, Windows 실행 파일, 설치·저장 복구 검사를 대신하지 않습니다.

## 현재 적용 범위

버튼, 안내, 진행률과 실제 설정 화면을 먼저 등록했습니다. 설정 전체 배치의 완성이나 기존 모든 알림의 공통화를 뜻하지 않습니다. 공통 값은 제품 CSS 토큰에서, 동작은 제품 컴포넌트에서 수정하며 예제용 UI를 따로 복제하지 않습니다.
