# 바로록 새 회의록 해양 테마 시안 계획

상태: B 고래꼬리 물결 방향 선택, 배경·하단 구성 보정 완료

초기 콘셉트: `new-record-whale-sunlight-draft.png`

프로젝트 내 보존 기준본: `new-record-whale-sunlight-theme.png`

선택된 최종 후보: `new-record-whale-tail-selected-no-footer.png`

구현 레이아웃 기준: `new-record-whale-theme-layout-spec.md`

선택 메모:

- 환경 배경은 `new-record-whale-sunlight-draft.png`의 선명한 고래·햇빛·산호 구성을 사용한다.
- 실행 버튼은 B 고래꼬리 물결 유리 버튼을 사용한다.
- 별도 하단 실행 영역, 흰 배경, 상단 구분선은 사용하지 않는다.
- 실행 버튼은 바다 작업면 위에 직접 두고 회의 정보 패널의 오른쪽 끝선에 맞춘다.

## 이번 디자인 작업의 목표

- 기존 고래·수면 햇빛·해양 생물 방향을 유지한다.
- 하단 실행 행에서는 `참석자 구분` UI를 제거한다.
- `분석 시작`을 단색 파란 버튼 대신 업로드 영역과 연결되는 바다색 유리 표면으로 만든다.
- 오른쪽 회의 정보 영역에도 해양 분위기를 주되 입력 가독성을 우선한다.
- 같은 레이아웃에서 환경 장면과 표면 효과를 교체할 수 있는 테마 구조를 전제로 한다.
- 세 가지 시안을 비교한 뒤 하나를 구현 기준으로 선택한다.

## 범위와 미결정 사항

### 디자인 범위

- 새 회의록 화면만 다룬다.
- 사이드바, 파일 업로드, 회의 정보, 실행 영역의 시각 구성만 비교한다.
- 수심, 좌표, 해도 눈금은 사용하지 않는다.
- 고래, 햇빛, 소수의 물고기, 해초·산호는 입력과 버튼을 침범하지 않는 환경층에 둔다.

### 기능 미결정

시안에서는 하단 `참석자 구분`을 제거한다. 실제 제품에 반영할 때는 다음 중 하나를 별도로 결정해야 한다.

- 기존 선택값을 유지하되 UI만 다른 위치로 이동한다.
- 항상 참석자 구분을 실행한다.
- 기본값을 따르며 이 화면에서는 변경할 수 없게 한다.

디자인 승인 전에는 기능 계약을 변경하지 않는다.

## 공통 레이아웃

```text
┌───────────┬──────────────────────────────────────────────┐
│           │  새 회의록                     고래 + 햇빛  │
│ 사이드바  ├────────────────────┬─────────────────────────┤
│           │                    │                         │
│           │  파일 업로드       │  회의 정보              │
│           │  물결 효과         │  읽기 가능한 표면       │
│           │                    │                         │
│           ├────────────────────┴─────────────────────────┤
│           │                         [ 유리 분석 시작 ]   │
└───────────┴──────────────────────────────────────────────┘
```

- 하단 실행 영역은 높이를 줄이고 `분석 시작` 하나만 오른쪽에 둔다.
- 업로드와 회의 정보는 넓은 화면에서 5:4 안팎의 2열을 유지한다.
- 장식 생물은 오른쪽 패널 바깥의 안전 영역에만 둔다.
- 1024px에서는 고래와 생물을 먼저 축소·숨기고 입력 영역을 보존한다.

## 시안 A — 해파리 유리 캡슐

비교 이미지: `new-record-action-a-jellyfish-glass.png`

### 분석 시작 버튼

- 둥근 직사각형의 안정적인 클릭 영역을 유지한다.
- 테두리는 밝은 청록 1px, 내부는 위쪽이 밝고 아래쪽이 깊은 반투명 바다색이다.
- 왼쪽에 단순화한 해파리 실루엣을 넣고 `분석 시작` 문구를 중앙에 둔다.
- hover에서는 해파리 촉수가 아니라 내부 빛이 아주 약하게 아래로 번진다.
- focus에서는 생물 형태와 무관한 2px 외곽 링을 사용한다.

### 오른쪽 회의 정보 효과

- 옅은 바다 유리 패널 안에 수면 채광을 닮은 매우 약한 상단 하이라이트를 둔다.
- 입력 필드 뒤에는 이미지나 물고기를 배치하지 않는다.
- 패널 오른쪽 바깥에 해초 실루엣과 작은 물고기 세 마리만 둔다.

### 인상

- 가장 부드럽고 친근하다.
- 버튼의 생물성이 명확하지만 업무용 인상도 유지하기 쉽다.

## 시안 B — 고래꼬리 물결 버튼

비교 이미지: `new-record-action-b-whale-tail-wave.png`

### 분석 시작 버튼

- 바다색 유리 캡슐 안에 고래 꼬리가 수면으로 내려가는 단순 아이콘을 둔다.
- 캡슐 오른쪽 끝의 곡률을 조금 크게 해 진행 방향을 표현한다.
- 버튼 내부에 얇은 한 줄 물결이 흐르지만 글자 아래를 지나가지 않는다.
- hover에서는 물결이 4~6px 이동하고 reduced motion에서는 정지한다.

### 오른쪽 회의 정보 효과

- 패널 상단 오른쪽에 고래가 지나간 흔적처럼 옅은 곡선 하이라이트를 둔다.
- 패널 테두리는 상단만 조금 밝고 나머지는 낮은 대비의 청록 hairline을 사용한다.
- 배경의 고래와 패널 효과가 같은 방향으로 흐르게 한다.

### 인상

- 고래 테마와 가장 직접적으로 연결된다.
- 세 안 중 브랜드 상징성이 가장 강하다.

## 시안 C — 가오리 글라스 플레이트

비교 이미지: `new-record-action-c-manta-glass.png`

### 분석 시작 버튼

- 실제 hit area와 포커스 외곽은 둥근 직사각형으로 유지한다.
- 내부 유리판의 위·아래 곡선을 가오리 날개처럼 아주 미세하게 처리한다.
- 작은 가오리 실루엣을 왼쪽에 두고 문구는 평평한 기준선에 유지한다.
- 형태가 과도하게 캐릭터처럼 보이지 않도록 대칭과 돌출을 제한한다.

### 오른쪽 회의 정보 효과

- 패널 배경에 대각선으로 흐르는 매우 약한 청록 깊이 그라데이션을 사용한다.
- 오른쪽 아래 바깥에 산호와 가오리 그림자를 한 겹만 둔다.
- 입력 영역 주변은 거의 흰색에 가깝게 유지한다.

### 인상

- 가장 독특하고 고급스럽다.
- CSS만으로 정확히 구현하기 어렵기 때문에 SVG 표면 마스크가 필요할 수 있다.

## 생물 모양 버튼 원칙

버튼의 외곽 전체를 물고기나 고래 모양으로 만들지 않는다.

- 실제 클릭 영역은 최소 44px 높이의 둥근 직사각형으로 유지한다.
- 생물성은 내부 실루엣, 유리 하이라이트, 물결, 제한된 곡선으로 표현한다.
- 포커스 링은 생물 외곽이 아니라 안정적인 버튼 경계를 따른다.
- `분석 시작`, `분석 중`, `다시 시도`처럼 문구가 달라져도 폭과 정렬이 무너지지 않아야 한다.
- 비활성 상태는 투명도만 낮추지 말고 테두리와 텍스트 대비도 함께 조정한다.
- 생물 에셋이 없어도 일반 유리 버튼으로 정상 표시되어야 한다.

## 테마 분리 기준

```text
고정 UI
  ├─ 레이아웃, 입력, 버튼 hit area, focus, 상태
환경 장면
  ├─ 고래, 햇빛, 물고기, 산호, 해초, 배경색
표면 스타일
  ├─ 업로드 유리, 회의 정보 유리, 실행 버튼 유리
상호작용 효과
  └─ 업로드 물결, 버튼 내부 물결, 햇빛의 미세 이동
```

- 테마 전환은 환경 장면과 표면 토큰만 교체한다.
- DOM 순서와 기능 컨트롤은 테마가 바뀌어도 유지한다.
- 장식 이미지는 접근성 트리에서 제외한다.
- 테마 에셋 로드 실패 시 단색 바다 그라데이션과 일반 유리 표면으로 대체한다.
