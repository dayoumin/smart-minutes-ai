문서 허브

개요 제품/디자인 평가/품질 운영 변환 후보 문서 추가 규칙

개요

바로록의 제품 계획, 사용자 학습, QA, 운영 문서를 모으는 시작점입니다. 새로 읽을 문서는 HTML 문서로 우선 연결하고, 기존 Markdown 문서는 변환 후보로 분리합니다.

제품/디자인

바로록 제품 전환 계획 해양·수산 정체성의 1인용 제품으로 전환하는 공통 화면, 웹 우선 순서와 후속 데스크톱 호환 기준입니다. 웹 우선 로컬 엔진 실행 계획 HTTPS 웹 UI, 사용자 다운로드형 Windows 로컬 엔진, 로컬 처리·저장과 단계별 웹 MVP 기준입니다. 바로록 프로덕션 디자인 구현 인계 승인된 여섯 화면을 공통 셸과 상태 구조로 옮기는 JSON 명세, 구현 순서, 중복·충돌 점검 기준입니다.

평가/품질

보고서 저장 수동 QA Word/한글 뷰어에서 DOCX/HWPX 보고서 저장 품질을 확인하는 체크리스트와 샘플 기준입니다.

운영

검토 요청 가이드 검토 범위와 요청 방식을 정리한 HTML 가이드입니다.

아래 문서는 현재 Markdown 원본입니다. 자주 참조하는 문서는 HTML로 변환한 뒤 이 허브의 대표 카드로 올립니다.

  • docs/airepoto-reference-adoption-plan.md: 보고서/회의록 완성도 계획

문서 추가 규칙

새 학습/설계/QA/운영 문서는 이 허브에 한 번만 연결합니다. 사용자에게 바로 보여줄 문서는 HTML로 만들고, 원본 로그, JSON, Markdown, 개발자용 스크립트는 변환 후보나 참고 자료로만 둡니다.
